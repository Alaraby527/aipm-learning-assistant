💬 高频面试题（点击展开参考答案）

每题含参考答案、评分要点、追问延伸和延伸阅读

如何设计一个 RAG 系统的评测方案？技术认知
参考答案要点：
1. 分层评测：检索层（召回率、MRR、NDCG）+ 生成层（忠实度、相关性、完整性）
2. 构建标注数据集：覆盖正确检索、错误检索、无答案等场景
3. 自动化指标 + 人工评测结合：LLM-as-Judge 用于批量初筛，人工评测用于关键场景
4. Bad Case 分析驱动迭代：定位是检索问题还是生成问题，针对性优化分块策略/重排序/Prompt
大模型产品如何做成本优化？商业判断
参考答案要点：
1. 模型路由：简单任务用小模型，复杂任务用大模型
2. Prompt 优化：减少冗余 token，使用更高效的指令格式
3. 缓存策略：高频查询结果缓存，语义缓存减少重复计算
4. 批处理与流式：非实时场景批量处理，实时场景流式输出降低感知延迟
5. 量化与蒸馏：针对特定场景使用微调小模型替代通用大模型
Agent 产品中如何设计人机协同机制？产品设计
参考答案要点：
1. 风险分级：低风险自动执行，中风险确认后执行，高风险必须人工审核
2. 可解释性：Agent 每个决策附带推理过程和依据，让人类能判断是否可信
3. 中断与接管：任何时刻人类可以中断 Agent 流程并接管
4. 反馈闭环：人类的修正反馈回传给 Agent，用于持续优化
5. 置信度阈值：Agent 置信度低于阈值时自动请求人工介入
AI 产品如何处理幻觉问题？技术认知
参考答案要点：
1. 检索增强（RAG）：让模型基于检索到的事实回答，而非纯生成
2. 约束生成：通过 Prompt 约束模型只使用提供的上下文，无依据时说"不知道"
3. 事实校验：输出后经过事实核查模块，检测与已知事实的矛盾
4. 置信度标注：对模型输出的每个声明标注置信度
5. 人工兜底：高风险场景必须人工审核，自动放行率设为 0%
作为 AI 产品经理，你如何评估一个新模型是否值得接入？产品基本功
参考答案要点：
1. 能力评测：在自有业务场景的测试集上对比新模型与现有模型的表现
2. 成本分析：token 单价、推理速度、并发能力对总成本的影响
3. 兼容性：API 格式、上下文长度、函数调用等能力是否满足需求
4. 风险评估：数据隐私、合规性、服务稳定性、SLA 保障
5. A/B 测试：小流量灰度验证真实业务指标提升，而非只看实验室指标
